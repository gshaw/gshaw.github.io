# Gerry's Personal Home Page

Jekyll site for Gerry's personal home page.

[Live Site](https://gshaw.ca)

## Build Instructions

```sh
brew install mise
mise install
mise run install
mise run dev
mise run deploy
```

Pushing to `main` publishes the site on Cloudflare Pages. `mise run check` runs the build,
spell check, Markdown lint and internal link check.
